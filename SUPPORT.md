# Support

8gnc 0.3.0 is staged for public-beta review. Version 0.2.1 remains the current tagged release until v0.3 is separately published.

## Before opening an issue

1. Confirm the exact 8gnc version and installation source.
2. Record the host application and version.
3. State whether the problem concerns a skill, the Markdown fallback, or the Working Diagnosis interface.
4. Run the host's plugin validation or diagnostics command.
5. Remove credentials, client data, private file paths, and sensitive evidence from logs or examples.

## Get help

- Installation or behavior issue: <https://github.com/Branded-Mayhem-Collective-LLC/8gnc-plugin/issues>
- Private security report: `hello@brandedmayhem.com`
- Product documentation: <https://8gnc.io/products/8gnc/support>

The renderer cannot log into a private account, retrieve a lost diagnosis, send an email, write to a CRM, or execute a recommendation. It has no account system or durable request storage.

Support covers this aggregate plugin. The six independent specialist repositories keep their existing issue trackers and release histories.
