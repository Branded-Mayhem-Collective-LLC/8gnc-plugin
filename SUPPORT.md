# Support

8gnc 0.2.0 is a public beta.

## Before opening an issue

1. Confirm you installed `8gnc@8gnc` from this repository.
2. Record your host application and version.
3. Run the host's plugin validation or diagnostics command.
4. Remove credentials, client data, and private file paths from logs or examples.

## Get help

- Installation or behavior issue: <https://github.com/Branded-Mayhem-Collective-LLC/8gnc-plugin/issues>
- Private security report: `hello@brandedmayhem.com`
- Product documentation: <https://8gnc.io/products/8gnc/support>

Support covers this aggregate plugin. The six independent specialist repositories keep their existing issue trackers and release histories.
