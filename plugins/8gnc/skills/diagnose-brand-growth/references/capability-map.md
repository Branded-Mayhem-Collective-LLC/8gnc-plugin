# 8gnc capability map

The bundle contains 36 unique specialist skills. The public six-package catalog counts 37 entries because `deep-research` serves both Brandprint and Productprint. The diagnostic router is the thirty-seventh folder in this Codex package.

## Brand meaning and positioning

Use when the question is who the brand is, why it matters, where it is distinct, or how to express it.

Typical sequence:

1. `core-human-truth`
2. `brandprint-tier-a`
3. `brandprint-tier-b`
4. `brandprint-tier-c`
5. `competitive-positioning-audit`
6. `brand-strategy-compiler`

Use `deep-research` when claims need current external evidence. Use `competitive-teardown` for category-wide whitespace. Use `brand-revival` when a previously coherent brand has gone stale or invisible. Read `brandprint-engine-guide` before running the full chain.

## Product direction and sequencing

Use when the question is what to build, for whom, how to win, in what order, or whether the strategy survives challenge.

Typical sequence:

1. `core-strategic-truth`
2. `productprint-tier-a`
3. `productprint-tier-b`
4. `productprint-tier-c`
5. `thesis-stress-test`
6. `strategy-thesis-compiler`

Use the shared `deep-research` engine for market evidence. Read `productprint-engine-guide` before running the full chain.

## Content and voice

Use when the strategy exists but the output sounds generic, inconsistent, or structurally weak.

- `voice-profiler` creates a reusable voice profile.
- `humanize` rewrites general prose using that profile.
- `humanize-ig` rewrites Instagram-native captions.
- `linkedin-authority` structures LinkedIn thought leadership.
- `story-spine` creates narrative shape.
- `creative-thinking-ai` expands and stress-tests ideas.
- `mayhem-method-ai-use` standardizes production workflows.
- `ai-focus-group` simulates reactions; label them synthetic, never user research.

## Search and AI visibility

Use when the brand cannot be found, understood, cited, or transacted with by search engines or agents.

- `dataforseo` runs keyword, SERP, backlink, and audit workflows when credentials and a supported local execution surface are available.
- `local-services-seo` designs city-by-service page systems.
- `ai-agent-readiness` tests whether agents can understand and use a site.
- `data-density-commerce` checks product-feed and schema completeness.
- `ai-visibility-tracking` measures brand mentions and citations when the required data access is available.

Never fabricate API results. On a surface without local execution or credentials, return the exact input contract and a clearly labeled analysis plan.

## Conversion and pricing architecture

Use when traffic exists but choice, pricing, flow, or visual hierarchy blocks action.

- `fairness-anchor-ladder` designs pricing anchors and upgrade economics.
- `ux-ui-psych` designs choice architecture with dark-pattern guardrails.
- `neuro-design` develops psychology-informed visual direction.

## Sales motion and practice

Use when the problem is reply rate, commodity framing, objection handling, or rehearsal.

- `outreach-diagnosis` identifies the root cause of weak outbound.
- `pitching-pivot` reframes commodity requests into strategic conversations.
- `sales-simulator` provides explicitly synthetic practice and scoring.

## Routing guardrails

- Do not run all lanes because the user asks for the "full treatment." Diagnose first, then justify each lane.
- Do not compile missing artifacts or silently invent them.
- Keep observed evidence separate from inference.
- Keep advice separate from execution.
- Stop at a decision gate before any external send, publish, purchase, deploy, or client-state mutation.
