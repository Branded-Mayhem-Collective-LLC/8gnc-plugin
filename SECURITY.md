# Security Policy

## Supported version

Security fixes are applied to the latest tagged public release. Version 0.2.x is the current public-beta line.

## Report a vulnerability

Email `hello@brandedmayhem.com` with the subject `8gnc security report`.

Include the affected version, the skill or file involved, reproduction steps, and the impact. Do not include real credentials, client data, private account exports, or other sensitive material. We will acknowledge a reproducible report within five business days and coordinate disclosure after a fix is available.

## Runtime boundary

8gnc is a skills-only package. It ships no MCP server, hook, telemetry service, or publisher-operated runtime. Individual host applications and optional third-party research services remain governed by their own security and privacy terms.
